## 문제 1: 백준 1197 — 최소 스패닝 트리 (Gold IV)

### 문제 요약
V개 정점, E개 간선으로 이루어진 무방향 그래프의 최소 신장 트리 가중치 합을 구하라.

### 입력
```
V E          (정점 수, 간선 수)
A B C        (A-B 가중치 C)
...
```

### 제약
- 1 ≤ V ≤ 10,000
- 1 ≤ E ≤ 100,000
- 가중치 -10,000 ≤ C ≤ 10,000 (음수 가능!)

### 풀이 전략
- 크루스칼 MST
- 음수 가중치도 크루스칼에서 문제없이 처리됨

## 문제 3: 백준 4386 — 별자리 만들기 (Gold III)

### 문제 요약
2D 좌표로 주어진 N개의 별을 최소 비용으로 연결하라.  
두 별 사이의 거리 = 유클리드 거리.

### 입력
```
N            (별의 수)
x y          (별 좌표)
...
```

### 제약
- 1 ≤ N ≤ 100
- 좌표 0.0 ≤ x, y ≤ 1000.0

### 풀이 전략
- 완전 그래프를 구성하면 E = N*(N-1)/2 ≤ 4,950 → 충분
- Prim 알고리즘 (좌표 기반 완전 그래프에서 유리)
- 또는 크루스칼 (모든 간선 생성 후 정렬)
