```
V E          (정점 수, 간선 수)

...
```

## 문제 3: 백준 1238 — 파티 (Gold III)

### 문제 요약
N명의 학생이 X번 마을로 파티를 가고 돌아온다.
이동 거리 = 집 → X + X → 집. 이 값의 최댓값을 구하라.

### 입력
```
N M X        (학생 수, 도로 수, 파티 마을)
a b t        (a→b, 시간 t)
...
```

### 제약
- 1 ≤ N ≤ 1,000
- 1 ≤ M ≤ 10,000
- 가중치 1 ≤ t ≤ 100

### 풀이 전략
1. **정방향 그래프**에서 X를 출발점으로 다익스트라 → X→i 최단 거리
2. **역방향 그래프**에서 X를 출발점으로 다익스트라 → i→X 최단 거리 (역방향의 X→i)
3. `max(go[i] + back[i])` 출력

역방향 그래프 기법: 모든 간선을 뒤집어서 다익스트라 1회만 추가 실행.
