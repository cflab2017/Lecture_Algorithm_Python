## 문제 1: 백준 11404 — 플로이드 (Gold IV)

### 문제 요약
n개 도시, m개 버스. 모든 도시 쌍 (i, j) 의 최소 비용 버스를 구하라.
도달 불가면 0 출력.

### 입력
```
n          (도시 수, 1 ≤ n ≤ 100)
m          (버스 수, 1 ≤ m ≤ 100,000)
a b c      (a→b 비용 c)
...
```

### 제약
- 1 ≤ n ≤ 100 → V³ = 10⁶ 충분
- 같은 (a, b) 버스가 여러 개 존재할 수 있음 → 최소값 선택

### 풀이 전략
- 기본 플로이드-워셜
- 출력 시 INF이면 0 출력

## 문제 2: 백준 1389 — 케빈 베이컨의 6단계 법칙 (Silver I)

### 문제 요약
N명의 사람 M개 관계. 케빈 베이컨 수 = 다른 모든 사람까지 최단 거리 합.
케빈 베이컨 수가 가장 작은 사람 번호를 출력.

### 입력
```
N M          (사람 수, 관계 수)
a b          (a-b 친구)
```

### 제약

## 문제 3: 백준 11403 — 경로 찾기 (Silver I)

### 문제 요약
가중치 없는 방향 그래프. i에서 j로 가는 경로가 있으면 1, 없으면 0인 행렬 출력.

### 입력
```
N            (노드 수, 1 ≤ N ≤ 100)
(N×N 인접 행렬)
```

### 풀이 전략
- 플로이드-워셜 OR 버전 (전이 폐쇄)
- `reach[i][j] |= reach[i][k] and reach[k][j]`
- 자기 자신(i==j)은 입력 행렬 기준 — 0으로 출력

## 제출 전 체크리스트

- [ ] k 루프가 가장 바깥: `for k → for i → for j`
- [ ] `dist[i][i] = 0` 초기화

- [ ] INF + w 오버플로 방지: `float('inf')` 또는 `if dist[i][k] == INF: continue`
- [ ] 출력 형식: 문제마다 도달불가 표현 다름 (0 또는 INF)
