## 문제 1: 백준 2003 — 수들의 합 2 (Silver IV)

### 문제 요약
N개의 수 A[0..N-1] 에서 연속 부분 배열의 합이 M인 경우의 수를 구하라.

### 입력
```
N M
A[0] A[1] ... A[N-1]
```

### 제약
- 1 ≤ N ≤ 10,000
- 1 ≤ M ≤ 300,000,000
- 모든 A[i] ≥ 1 (양수 → 투 포인터 가능)

### 풀이 전략
- 같은 방향 투 포인터
- lo=hi=0, 합이 M 이상이면 lo 전진, 합이 M이면 count++

## 문제 2: 백준 11003 — 최솟값 찾기 (Platinum V)

### 문제 요약
N개의 수 A에서 각 i에 대해 max(0, i-L+1) ~ i 구간의 최솟값을 출력하라.

### 입력
```
N L
A[0] A[1] ... A[N-1]
```

### 제약
- 1 ≤ N ≤ 5,000,000
- 1 ≤ L ≤ N
- -10⁹ ≤ A[i] ≤ 10⁹

### 풀이 전략
- deque 슬라이딩 윈도우 단조 증가 덱
- O(n) 시간, O(L) 공간
- sys.stdin.readline + sys.stdout.write 로 I/O 최적화

## 문제 3: 백준 11659 — 구간 합 구하기 4 (Silver III)

### 문제 요약
N개 수에 대해 M번의 구간 합 쿼리 [l, r] 을 처리하라.

### 입력
```
N M
A[1] A[2] ... A[N]
i j  (i ~ j 구간 합)
...
```

### 제약
- 1 ≤ N ≤ 100,000
- 1 ≤ M ≤ 100,000
- 1-indexed

### 풀이 전략
- `prefix[i] = prefix[i-1] + A[i]` 전처리
- `query(l, r) = prefix[r] - prefix[l-1]`

## 문제 4: 백준 2098 — 외판원 순회 (Gold I)

### 문제 요약
N개 도시를 한 번씩 방문하고 출발점으로 돌아오는 최소 비용을 구하라.
W[i][j] = i→j 비용 (0이면 없음).

### 입력
```
N
W[0][0] ... W[0][N-1]
...
```

### 제약
- 1 ≤ N ≤ 16
- 0 ≤ W[i][j] ≤ 100,000

### 풀이 전략
- 비트마스크 DP: `dp[mask][v]` = mask 방문 집합, 현재 v에서의 최소 비용
- `dp[1<<N - 1][v] + W[v][0]` 의 최솟값이 답
- 메모이제이션(top-down) 또는 타뷸레이션(bottom-up) 둘 다 가능

### 풀이 파일
[answer/boj_2098.py](answer/boj_2098.py)
