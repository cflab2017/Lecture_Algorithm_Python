# 강의 19 과제: 트라이

## 문제 1: 백준 14425 — 문자열 집합 (Silver III)

**링크**: https://www.acmicpc.net/problem/14425

### 문제 요약
N개의 문자열로 집합 S를 만들고, M개의 문자열이 S에 속하는지 개수를 세어라.

### 입력 형식
```
5 11
baekjoononlinejudge
...
```

### 핵심 접근법
- **set() 풀이**: O(n×m + m×m) — Python 기본 자료구조로 간단 해결
- **트라이 풀이**: O((n+m)×m) — 트라이로 학습 목적 구현

### 시간/공간 복잡도
- Time: O((n + m) × m_avg)
- Space: O(n × m_max)

### 주의사항
- n, m ≤ 10,000, 문자열 길이 ≤ 500
- Python set으로 충분히 풀리지만, 트라이 구현 연습용

## 문제 2: 백준 5052 — 전화번호 목록 (Gold IV)

**링크**: https://www.acmicpc.net/problem/5052

### 문제 요약
전화번호 목록이 일관성이 있는지 확인하라.  
(어떤 번호가 다른 번호의 접두사이면 "NO")

### 입력 형식
```
2
3
911
97625999
91125426
5
113
12340
123440
12345
98346
```

### 출력 형식
```
NO
YES
```

### 핵심 접근법
트라이에 삽입 시 중간에 is_end인 노드를 만나면 "NO"  
또는 삽입 완료 후 자식이 있는 is_end이면 "NO"

### 시간/공간 복잡도
- Time: O(n × m) — n = 번호 수, m = 최대 길이
- Space: O(n × m)
