# 강의 17 과제: 트리 순회

## 문제 1: 백준 1991 — 트리 순회 (Silver I)

**링크**: https://www.acmicpc.net/problem/1991

### 문제 요약
이진 트리가 문자(A~Z)로 표현될 때, 전위/중위/후위 순회 결과를 출력하라.

### 입력 형식
```
7
A B C
B D .
C E F
D . .
E . . 
F . G
G . .
```
(`.` = 자식 없음)

### 출력 형식
```
ABDCEFG    ← 전위
DBAECFG    ← 중위
DBEGFCA    ← 후위
```

### 핵심 포인트
- 딕셔너리로 트리 표현: `tree[node] = (left, right)`
- `.`은 None으로 처리
- 재귀 순회 그대로 적용

### 시간/공간 복잡도
- Time: O(n) — 노드 수 n
- Space: O(n) — 딕셔너리 + 재귀 스택

## 문제 2: 백준 11725 — 트리의 부모 찾기 (Silver II)

**링크**: https://www.acmicpc.net/problem/11725

### 문제 요약
루트가 1인 트리에서 각 노드의 부모를 구하라.

### 입력 형식
```
7
1 6
6 3
3 5
4 1
2 4
4 7
```

### 출력 형식
```
4
6
1
3
1
4
```
(2번~n번 노드의 부모 순서로)

### 핵심 포인트
- 무향 그래프로 입력 → BFS/DFS로 루트(1)에서 탐색
- 부모 배열 `parent[v] = u` 갱신
- 방문 처리 필수 (무한 루프 방지)

### 시간/공간 복잡도
- Time: O(n) — BFS/DFS
- Space: O(n) — 인접 리스트 + parent 배열
