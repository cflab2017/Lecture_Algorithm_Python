# 파이썬 알고리즘 & 자료구조 강의

> 백준 골드 수준 · 프로그래머스 Lv.3 · 코딩 테스트 합격을 목표로 하는 파이썬 알고리즘 완성 커리큘럼

---

## 학습 목표

| 목표 | 기준 |
|------|------|
| 백준 온라인 저지 | 골드 I ~ V 수준 문제 독립 풀이 |
| 프로그래머스 | Lv. 3 문제 70% 이상 통과 |
| 코딩 테스트 | 삼성 SW 역량 / 카카오 / 네이버 등 기업 코딩 테스트 합격 |

---

## 개발 환경

```
Python  : 3.10 이상 (match-case, structural pattern matching 사용)
편집기   : VS Code + Python 확장 (pylint, black)
가상환경 : python -m venv .venv && source .venv/bin/activate
```

### 리소스 제한 기준 (코딩 테스트 공통)

| 항목 | 기준 | 비고 |
|------|------|------|
| 시간 제한 | 1초 ≈ 1억(10⁸) 연산 | PyPy 사용 시 약 3~5배 빠름 |
| 메모리 제한 | 256 MB | int 하나 ≈ 28 bytes (CPython) |
| 재귀 깊이 | 기본 1,000 | `sys.setrecursionlimit(10**6)` 필요 |

## 학습 순서 권장

```
1주차  : 단원 01 ~ 03  (입출력, 배열, 재귀)
2주차  : 단원 04 ~ 06  (정렬, 이진 탐색, 해시)
3주차  : 단원 07 ~ 09  (스택, 큐, 우선순위 큐)
4주차  : 단원 10 ~ 12  (트리, 힙, 세그먼트 트리)
5주차  : 단원 13 ~ 16  (그래프 기초, BFS, DFS, 위상 정렬)
6주차  : 단원 17 ~ 18  (DP 기초 ~ 중급)
7주차  : 단원 19 ~ 20  (LCS/LIS, 배낭 문제)
8주차  : 단원 21 ~ 22  (트리 DP, 구간 DP)
9주차  : 단원 23 ~ 24  (유니온-파인드, 다익스트라)
10주차 : 단원 25 ~ 26  (플로이드-워셜, MST)
11주차 : 단원 27      (실전 패턴 통합)
12주차 : 전체 복습 + 모의 코딩 테스트
```

> **권장**: 1주 2~3단원, **12주 완주** 목표.
> 각 단원은 개념 → 예제 → 과제 순서로 학습하고, 과제를 직접 풀어 본 뒤 풀이를 확인하세요.
