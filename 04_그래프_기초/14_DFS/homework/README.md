## 문제 1: 백준 2606 – 바이러스 (Silver III)

### 접근법
- 컴퓨터 1에서 DFS 탐색
- 방문한 노드 수 - 1 (1번 컴퓨터 제외)

## 문제 2: 백준 2667 – 단지번호붙이기 (Silver I)

### 문제 설명
NxN 격자에서 연결된 집들을 단지로 묶고,
단지 수와 각 단지 크기를 오름차순 출력.

### 입력 형식
```
7
0110100
0110100
1110000
0000011
0100010
1100000
```

### 접근법
```python
for r in range(n):
    for c in range(n):
        if grid[r][c] == 1 and not visited[r][c]:
            size = dfs(r, c)
            sizes.append(size)
```

### 주의사항
- 입력이 문자열 → int로 변환 필요
- 경계 체크 필수

## 문제 3: 백준 1012 – 유기농 배추 (Silver II)

### 문제 설명
MxN 격자에서 배추가 심어진 연결 요소의 수를 구하세요.
(지렁이 한 마리가 한 연결 요소 담당)

### 접근법
2667과 동일하지만:
- 테스트 케이스 여러 개
- M×N 격자 (M≠N 가능)
- 배추 좌표가 (x, y) 로 주어짐 → (행, 열) 변환 주의
