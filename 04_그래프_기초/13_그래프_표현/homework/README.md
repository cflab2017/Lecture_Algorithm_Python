## 문제 1: 백준 1260 – DFS와 BFS (Silver II)

### 문제 설명
N개의 노드, M개의 간선, 시작 V.
DFS와 BFS로 각각 방문 순서 출력.

### 입력
```
4 5 1
1 2
1 3
1 4
2 4
3 4
```

### 접근법
- 인접 리스트 구축 (무방향)
- 번호가 작은 노드부터 방문 → 정렬 필요
- DFS: 재귀 또는 스택
- BFS: deque

### 주의사항
- 각 노드의 인접 리스트를 **정렬**해야 번호 작은 것부터 방문
- visited 배열 초기화 잊지 말 것

## 문제 2: 백준 11724 – 연결 요소의 개수 (Silver II)

### 문제 설명
무방향 그래프에서 연결 요소의 개수를 출력.

### 접근법
```python
count = 0
visited = [False] * (n + 1)
for node in range(1, n + 1):
    if not visited[node]:
        dfs(node)     # or bfs(node)
        count += 1
```

### 주의사항
- 방향 없는 그래프 (무방향)
- 고립된 노드도 연결 요소 1개로 카운트
