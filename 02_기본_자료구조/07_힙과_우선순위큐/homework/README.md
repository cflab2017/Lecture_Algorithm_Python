## 문제 1: 백준 1927 -- 최소 힙 (Silver II)

**링크**: https://www.acmicpc.net/problem/1927

### 문제 설명
널리 잘 알려진 자료구조 중 최소 힙이 있다.
최소 힙을 이용하여 다음과 같은 연산을 지원하는 프로그램을 작성하시오.

- 자연수 x를 집합에 넣는다.
- 집합에서 가장 작은 값을 출력하고 그 값을 제거한다. (집합이 비어있으면 0 출력)

### 입력/출력
```
9          (N)
0          -> 0 (빈 힙)
12345678   -> push
1          -> push
2          -> push
0          -> 1
0          -> 2
0          -> 12345678
0          -> 0 (빈 힙)
32         -> push
0          -> 32
```

### 힌트
- `heapq` 사용
- x == 0 이면 pop 연산
- **Time O(N log N), Space O(N)**

## 문제 2: 백준 11279 -- 최대 힙 (Silver II)

**링크**: https://www.acmicpc.net/problem/11279

### 문제 설명
최소 힙과 동일하지만 최대 힙을 구현한다.
가장 **큰** 값을 출력하고 제거한다.

### 힌트
- 음수 변환 트릭: push 시 `-x`, pop 시 `-` 부호 복원
- **Time O(N log N), Space O(N)**

---

## 문제 3: 백준 11286 -- 절댓값 힙 (Silver I)

**링크**: https://www.acmicpc.net/problem/11286

### 문제 설명
절댓값이 가장 작은 값을 출력하는 힙을 구현한다.
절댓값이 같으면 음수를 먼저 출력한다.

### 입력/출력 예시
```
18
1 -> push 1
-1 -> push -1
0 -> -1 (|−1|=1 < ... 같으면 음수 먼저)
0 -> 1
...
```

### 힌트
- 튜플 (|x|, x) 를 힙에 넣으면 자동으로 절댓값 기준 정렬
- 절댓값이 같을 때 음수가 먼저: (-1, -1) vs (1, 1) -> (-1, -1) < (1, 1)
- **Time O(N log N), Space O(N)**
