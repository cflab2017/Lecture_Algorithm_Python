## 문제 1: 백준 1546 — 평균

- **링크**: <https://www.acmicpc.net/problem/1546>
- **난이도**: Bronze I
- **핵심 개념**: 배열 순회, O(n) 알고리즘 설계

### 문제 요약

세준이는 성적을 다음과 같이 조작하려 합니다.

1. 과목 점수들 중 **최댓값 M**을 찾는다.
2. 모든 점수를 `점수 / M * 100`으로 바꾼다.
3. 새 점수들의 평균을 출력한다.

입력: 첫 줄에 N (1 ≤ N ≤ 1000), 둘째 줄에 N개의 점수 (0 ≤ 점수 ≤ 100)

### 복잡도 분석 힌트

| 단계 | 연산 | 복잡도 |
|------|------|--------|
| 최댓값 탐색 | 배열 1회 순회 | O(n) |
| 합 계산 | 배열 1회 순회 | O(n) |
| 전체 | 배열 2회 순회 | **O(n)** |

- N ≤ 1,000이므로 어떤 풀이도 통과하지만, **O(n)으로 풀 수 있는지** 확인하세요.

## 문제 2: 백준 2750 — 수 정렬하기

- **링크**: <https://www.acmicpc.net/problem/2750>
- **난이도**: Bronze II
- **핵심 개념**: 정렬 알고리즘 구현, O(n²) vs O(n log n) 비교 체험

### 문제 요약

N개의 수를 정렬하여 출력합니다.

입력: N (1 ≤ N ≤ 1,000), 이후 N개의 정수 (각 줄)

### 과제 요구 사항

1. **버블 정렬**(O(n²))로 먼저 구현하세요.
2. 동일한 입력에 **`sorted()`**(O(n log n))로도 구현하세요.
3. 두 코드를 모두 `boj_2750.py`에 작성하고, 어느 것이 더 빠른지 주석으로 분석하세요.

### 복잡도 비교

```
N = 1,000
버블정렬: N² = 1,000,000 연산 → 느릴 수 있음
sorted(): N log N ≈ 10,000 연산 → 빠름

N ≤ 1,000이므로 버블정렬도 통과하지만,
N = 100,000이라면 버블정렬은 TLE!
```

## 문제 3: 백준 10989 — 수 정렬하기 3

- **링크**: <https://www.acmicpc.net/problem/10989>
- **난이도**: Bronze I
- **핵심 개념**: 계수 정렬(Counting Sort), O(n) 시간복잡도, 메모리 제한 처리

### 문제 요약

N개의 수를 정렬하여 출력합니다.

입력: N (1 ≤ N ≤ **10,000,000**), 이후 N개의 정수 (1 ≤ 값 ≤ 10,000)

### 왜 어려운가?

| 풀이 | 복잡도 | N=10,000,000일 때 | 결과 |
|------|--------|-------------------|------|
| `sorted()` | O(n log n) | ~2.3억 연산 | **MLE/TLE** (파이썬) |
| 버블정렬 | O(n²) | 10¹⁴ 연산 | **TLE** |
| 계수 정렬 | O(n + k) | ~1000만 연산 | **통과** |

- **메모리 문제**: N=10,000,000개를 전부 리스트에 저장하면 메모리 초과!
- **해결책**: 값의 범위(1~10,000)가 작으므로 카운터 배열(크기 10,001)만 사용

### 계수 정렬 원리

```
입력: [3, 1, 4, 1, 5, 9, 2, 6]

카운터 배열 (인덱스 = 값):
count[1] = 2  (1이 2번 등장)
count[2] = 1
count[3] = 1
...

출력: 1을 2번, 2를 1번, 3을 1번, ... 순서로 출력
→ 1 1 2 3 4 5 6 9
```

### 주의 사항

- 입력을 `sys.stdin`으로 받아야 TLE를 피할 수 있습니다.
- 출력도 `sys.stdout.write`나 `'\\n'.join()`으로 한 번에 출력해야 합니다.
