## 문제 1: 백준 15552 — 빠른 A+B

- **링크**: <https://www.acmicpc.net/problem/15552>
- **난이도**: Silver V
- **핵심 개념**: 빠른 입출력 — `sys.stdin`, `sys.stdout`

### 문제 요약

T개의 테스트 케이스가 주어집니다. 각 테스트 케이스에서 A와 B를 입력받아 A+B를 출력합니다.

```
입력:
5
1 1
12 34
5 500
40 60
1000 1000

출력:
2
46
505
100
2000
```

### 왜 빠른 I/O가 필요한가?

- T ≤ 1,000,000 (백만 번의 입출력)
- `input()`을 100만 번 호출하면 약 **5~10초** → 시간 초과
- `sys.stdin.readline()`을 사용하면 약 **0.5~1초** → 통과

### 요구 사항

1. `sys.stdin` 사용 (반드시)
2. 출력을 버퍼에 모아 한 번에 출력 (권장)
3. 상단에 시간복잡도, 공간복잡도 주석 필수

### 복잡도 분석

| 항목 | 값 |
|------|-----|
| 시간복잡도 | O(T) |
| 공간복잡도 | O(T) (출력 버퍼) |

## 문제 3: 백준 11022 — A+B - 8

## 팁

```python
# 15552번에 최적화된 템플릿
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    output = []
    for _ in range(T):
        a, b = map(int, input().split())
        output.append(str(a + b))
    sys.stdout.write('\n'.join(output) + '\n')

solve()
```
