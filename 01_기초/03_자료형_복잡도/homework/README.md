## 문제 1: 백준 1927 — 최소 힙

- **링크**: <https://www.acmicpc.net/problem/1927>
- **난이도**: Silver II
- **핵심 개념**: `heapq` 모듈, O(log n) 삽입/삭제

### 문제 요약

다음 두 연산을 지원하는 프로그램을 작성하세요.

- 자연수 x를 집합에 삽입 (`x > 0`)
- 집합에서 가장 작은 값을 출력하고 제거 (`x == 0`)
  - 집합이 비어 있으면 0 출력

```
입력:
9
0
12345678
1
2
0
0
0
0
0

출력:
0
1
2
12345678
0
0
```

### 복잡도 분석

| 연산 | 자료구조 | 시간복잡도 |
|------|----------|------------|
| 삽입 | `heapq.heappush` | O(log n) |
| 최솟값 제거 | `heapq.heappop` | O(log n) |
| 전체 | N번 연산 | O(N log N) |

## 문제 2: 백준 11279 — 최대 힙

- **링크**: <https://www.acmicpc.net/problem/11279>
- **난이도**: Silver II
- **핵심 개념**: `heapq` 최댓값 트릭 (음수 변환)

### 문제 요약

1927번과 동일하지만, 가장 **큰** 값을 출력합니다.

파이썬의 `heapq`는 **최솟값 힙**이므로, 최댓값을 구하려면 값을 음수로 변환하여 저장합니다.

```
# 최댓값 힙 트릭
heapq.heappush(heap, -x)    # 음수로 저장
max_val = -heapq.heappop(heap)  # 꺼낼 때 다시 음수
```

## 문제 3: 백준 1676 — 팩토리얼 0의 개수

- **링크**: <https://www.acmicpc.net/problem/1676>
- **난이도**: Bronze I
- **핵심 개념**: 수학적 분석, O(log n)

### 문제 요약

N! 에서 뒤에서부터 처음 0이 아닌 숫자가 나올 때까지 0의 개수를 구합니다.

```
입력: 10
출력: 2     (10! = 3628800)
```

### 풀이 힌트

N! 끝에 붙는 0의 개수 = N!에 포함된 소인수 5의 개수

```
10! 끝의 0 개수 = floor(10/5) + floor(10/25) + ... = 2 + 0 = 2
```

| N | floor(N/5) | floor(N/25) | floor(N/125) | 합 |
|---|------------|-------------|--------------|-----|
| 10 | 2 | 0 | 0 | **2** |
| 25 | 5 | 1 | 0 | **6** |
| 100 | 20 | 4 | 0 | **24** |

### 복잡도 분석

| 풀이 | 시간복잡도 | 공간복잡도 |
|------|------------|------------|
| 직접 계산 후 세기 | O(N) or O(N²) → **MLE** | O(N) |
| 소인수 5 개수 세기 | **O(log₅ N)** | O(1) |
