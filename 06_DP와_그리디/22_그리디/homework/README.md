# 강의 22 과제: 그리디

## 문제 1: 백준 1931 — 회의실 배정 (Silver I)

**링크**: https://www.acmicpc.net/problem/1931

### 문제 요약
n개의 회의 (시작, 끝)가 주어질 때, 한 회의실에서 최대 몇 개의 회의를 할 수 있는가.

### 핵심 접근법
1. 종료 시간 기준 오름차순 정렬
2. 종료 시간이 같으면 시작 시간 기준 오름차순 (중요!)
3. 그리디: 현재 회의 시작 >= 마지막 선택 종료 → 선택

### 함정
- 종료 시간이 같을 때 시작 시간 정렬 필요
- 시작 = 종료 (길이 0 회의) 처리

### 시간/공간 복잡도
- Time: O(n log n), Space: O(n)

## 문제 2: 백준 11047 — 동전 0 (Silver I)

**링크**: https://www.acmicpc.net/problem/11047

### 문제 요약
금액 k를 만들기 위한 최소 동전 수. 동전은 배율이 보장됨.

### 핵심 접근법
큰 동전부터 그리디 (동전값이 배율 보장되므로 그리디 최적)

### 시간/공간 복잡도
- Time: O(n), Space: O(n)

---

## 문제 3: 백준 1744 — 수 묶기 (Gold IV)

**링크**: https://www.acmicpc.net/problem/1744

### 문제 요약
수열에서 숫자를 묶어 곱하거나 그냥 더해서 최대 합을 구하라. (묶으면 곱으로 대체)

### 핵심 접근법
- 양수: 큰 것끼리 곱하기 (내림차순 2개씩)
- 음수: 작은 것(절댓값 큰)끼리 곱하기 (오름차순 2개씩)
- 1은 곱하면 손해 → 그냥 더하기
- 0과 홀수 개 음수 → 0과 묶어 소거

### 시간/공간 복잡도
- Time: O(n log n), Space: O(n)
